========================================================
 경남수학문화관 학교체험 SW프로그램 타이머 - 설치 안내
========================================================

■ 가장 쉬운 방법 : 설치 파일
  1) GitHub 저장소 → Releases → "타이머 실행파일 (최신)" 에서 GNMC-Timer-Setup.exe 를 받는다
  2) 더블클릭 → "바탕 화면에 바로 가기", "Windows 시작 시 타이머 자동 실행" 체크 → 설치
     (관리자 권한 필요 없음. 사용자 폴더에 설치됨)
  3) 설치가 끝나면 바로 타이머가 뜬다. 다음부터는 바탕 화면 아이콘 또는 재부팅 시 자동 실행
  4) 종료: 화면 오른쪽 위 ✕ → [종료]   (또는 Alt + F4)
  5) 제거: Windows 설정 → 앱 → "경남수학문화관 타이머" → 제거
  - 처음 실행 시 Windows SmartScreen 경고가 뜨면 "추가 정보" → "실행" 을 누른다
  - 켤 때마다 인터넷으로 새 버전을 확인해 화면(timer.html)을 자동 갱신한다 (아래 "자동 업데이트" 참고)
  - 설치 없이 쓰려면 같은 곳의 GNMC-Timer-win.zip 을 풀어 GNMC-Timer.exe 를 실행해도 된다

아래는 설치 파일 대신 bat + PowerShell 스크립트로 실행하는 방법(대안)이다.

■ 준비물 (모두 같은 폴더에 둘 것, 예: C:\timer\)
  - timer.html       타이머 화면 본체
  - launcher.ps1     업데이트 확인 + Edge 전체화면 실행
  - 타이머시작.bat   더블클릭용 실행 파일 (launcher.ps1 을 호출)
  - version.txt      현재 설치된 버전 (자동 관리, 손대지 않아도 됨)
  - 설치안내.txt     이 문서

  가장 쉬운 방법: GitHub 저장소 페이지에서 [Code] → [Download ZIP] 을 받아
  압축을 풀고 폴더째 C:\timer\ 로 옮기면 됩니다.


■ 1단계 : 실행 테스트
  타이머시작.bat 을 더블클릭 → Edge가 전체화면 타이머로 뜨면 성공.
  (종료할 때는 Ctrl + Shift + W  또는  Alt + F4)


■ 2단계 : 컴퓨터 켜지면 자동 실행되게 하기
  1) 키보드에서  Win + R  →  shell:startup  입력 후 엔터
  2) 열린 "시작프로그램" 폴더에  타이머시작.bat 의 "바로 가기" 를 만들어 넣기
     (bat 파일에서 마우스 오른쪽 → 바로 가기 만들기 → 그 바로 가기를 이동)
     ※ bat 파일 자체를 복사해 넣으면 launcher.ps1 을 찾지 못해 실행되지 않습니다.
  3) 이제 로그인하면 타이머가 자동으로 뜹니다.


■ 3단계 (선택) : 로그인 화면도 건너뛰기 - 완전 무인 운영
  1) Win + R  →  netplwiz  입력 후 엔터
  2) "사용자 이름과 암호를 입력해야..." 체크 해제
  3) 확인 → 계정 암호 2번 입력
  4) 재부팅하면 로그인 없이 바로 타이머까지 실행됩니다.


■ 자동 업데이트
  - 타이머를 켤 때마다 GitHub(i20091119-ai/2026.time) 의 version.txt 를 확인합니다.
  - 버전이 달라졌으면 최신 timer.html 을 내려받아 교체한 뒤 실행합니다.
  - 인터넷이 안 되거나 서버 오류면 그냥 기존 파일로 실행합니다. (타이머는 항상 뜸)
  - 확인 결과는 같은 폴더의 update.log 에 기록됩니다.
  - 화면 오른쪽 아래 키보드 안내 줄 끝에 현재 버전(v2026.09.22.1 등)이 표시됩니다.


■ 화면 구성 (세로형 키오스크, 아래 1/3 은 책상에 가려짐)
  - 상단 1/3 : 로고 + 오늘 날짜 + 현재 시각
  - 중간 1/3 : 타이머 (남은 시간, 5/20/25분 프리셋, 시작/초기화)
  - 하단 1/3 : 공백


■ 참고
  - 소리(삐빅)는 시작 버튼을 누른 뒤부터 납니다. (브라우저 자동재생 정책)
    부팅 후 소리가 안 나면 윈도우 볼륨/음소거부터 확인하세요.
  - 크롬을 쓰고 싶으면 launcher.ps1 의 $edge 부분을 크롬 경로로 바꾸면 됩니다.
