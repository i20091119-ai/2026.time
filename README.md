# 경남수학문화관 SW체험 타이머 (세로형 키오스크용)

세로형 키오스크(1080×1920 등)에서 체험 시간을 안내하는 타이머입니다.
Windows + Microsoft Edge 키오스크 모드로 실행되며, **켤 때마다 이 저장소를 확인해 자동 업데이트**됩니다.

## 화면 구성

키오스크 아래 1/3 은 책상에 가려지므로 화면을 세로로 3등분해 씁니다.

| 영역 | 내용 |
|---|---|
| 상단 1/3 | 로고 · 오늘 날짜 · **현재 시각**(크게) |
| 중간 1/3 | **타이머** (남은 시간 원형 표시, 5/20/25분 프리셋, 시작/일시정지, 초기화, 키보드 안내) |
| 하단 1/3 | 공백 |

## 설치 (권장)

[Releases → 타이머 실행파일 (최신)](https://github.com/i20091119-ai/2026.time/releases/tag/latest) 에서 **`GNMC-Timer-Setup.exe`** 를 받아 실행합니다.

1. 설치 파일 더블클릭 (관리자 권한 불필요, 사용자 폴더 `%LOCALAPPDATA%\GNMC-Timer` 에 설치)
2. "바탕 화면에 바로 가기", "Windows 시작 시 타이머 자동 실행" 을 체크 → 설치
3. 끝. 바탕 화면의 "경남수학문화관 타이머" 로 실행하거나, 재부팅하면 자동으로 뜹니다.

제거는 Windows 설정 → 앱 → "경남수학문화관 타이머" 에서 하면 됩니다.

동작:
- 항상 전체화면(테두리 없음, 맨 위)으로 뜨고, 화면 오른쪽 위 ✕ 버튼 → "종료" 로 끝냅니다. Alt + F4 도 됩니다.
- 켤 때마다 GitHub `main` 의 `version.txt` 를 확인해 `timer.html` 이 바뀌었으면 새로 받습니다. 인터넷이 없으면 그냥 기존 화면으로 뜹니다.
- 필요한 것: Windows 10/11 + Microsoft Edge (WebView2 런타임, 기본 포함). .NET Framework 4.8 은 Windows 에 기본 내장.
- 설치 파일과 zip 은 `main` 에 올라올 때마다 GitHub Actions(`.github/workflows/build-exe.yml`) 가 자동으로 빌드해 Releases 의 `latest` 에 갱신합니다. 소스는 `app/`, 설치 스크립트는 `app/installer.iss`.

설치 없이 쓰려면 같은 곳의 `GNMC-Timer-win.zip` 을 풀어 `GNMC-Timer.exe` 를 실행해도 됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `timer.html` | 타이머 화면 본체. 로고 이미지 내장, 단독 실행 가능 |
| `app/` | Windows 실행파일 소스 (C#, WinForms + WebView2). CI 가 빌드 |
| `launcher.ps1` | (스크립트 방식, 대안) 업데이트 확인/적용 후 Edge 전체화면으로 `timer.html` 실행 |
| `타이머시작.bat` | (스크립트 방식, 대안) 더블클릭용. `launcher.ps1` 을 호출 |
| `version.txt` | 현재 버전. **배포할 때 이 값을 바꾸면 키오스크가 업데이트를 받아감** |
| `설치안내.txt` | 키오스크 PC 설치 절차 |
| `docs-인수인계.md` | 인수인계 문서 (기능·수정 위치 설명) |

## 키오스크 PC 설치 (스크립트 방식, exe 를 못 쓸 때)

1. 저장소를 ZIP 으로 내려받아(Code → Download ZIP) 압축을 풀고 폴더째 `C:\timer\` 로 옮깁니다.
2. `타이머시작.bat` 더블클릭 → Edge 전체화면 타이머가 뜨면 성공.
3. 부팅 시 자동 실행: `Win + R` → `shell:startup` → 열린 폴더에 `타이머시작.bat` 의 **바로 가기**를 넣습니다.

자세한 절차는 `설치안내.txt` 참고.

## 자동 업데이트 동작

`타이머시작.bat` → `launcher.ps1` 이 실행될 때:

1. `https://raw.githubusercontent.com/i20091119-ai/2026.time/main/version.txt` 를 읽는다 (8초 제한).
2. 로컬 `version.txt` 와 다르면 `timer.html`, `launcher.ps1`, `설치안내.txt` 를 임시 폴더에 내려받는다.
3. 전부 정상 수신되면 파일을 교체하고 `version.txt` 를 갱신한다. 하나라도 실패하면 **기존 파일 그대로** 둔다.
4. 인터넷이 없거나 같은 버전이면 아무것도 바꾸지 않는다.
5. Edge 키오스크로 `timer.html?v=버전` 을 연다. 화면 오른쪽 아래에 `v버전` 이 표시된다.

결과는 같은 폴더의 `update.log` 에 남습니다.

### 새 버전 배포하기

1. `timer.html` 을 수정한다.
2. `version.txt` 의 값을 올린다 (예: `2026.09.22.1` → `2026.09.23.1`). 형식은 자유, **값이 달라지기만 하면** 업데이트로 인식.
3. `main` 브랜치에 반영(머지)한다.
4. 키오스크는 다음 실행(재부팅) 때 자동으로 새 파일을 받는다.

## 조작

| 키 | 동작 |
|---|---|
| 1 / 2 / 3 | 5분 / 20분 / 25분 설정 |
| 4 | 초기화 |
| Enter 또는 Space | 시작 / 일시정지 |

- 남은 1분 이하: 숫자·링 빨간색
- 종료 30초 전부터 매초 삐빅, 마지막 5초는 높은 음, 종료 시 화면 깜빡임 + 긴 알림음
- 좌상단 ⛶ 전체화면 토글(브라우저에서만), 우상단 ▁ 최소화(숫자만 크게), ✕ 종료(확인 창 뜸)
- 소리는 브라우저 정책상 첫 조작(시작 버튼 등) 이후 재생됨

## 웹으로 열기 (GitHub Pages)

저장소 설정에서 Pages 를 `main` / `(root)` 로 켜 두면 아래 주소에서 항상 최신 타이머가 열립니다.

```
https://i20091119-ai.github.io/2026.time/
```

키오스크에서 이 주소를 직접 쓸 수도 있지만(항상 최신, 업데이트 스크립트 불필요), 부팅 때 인터넷이 없으면 화면이 뜨지 않습니다.
무인 운영에는 로컬 파일 + `launcher.ps1` 방식이 안전하고, Pages 주소는 미리 보기·공유용으로 쓰는 것을 권합니다.

## 로컬에서 확인

`timer.html` 을 브라우저로 열면 됩니다. 세로 화면 확인은 개발자 도구의 기기 모드에서 1080×1920 으로 보면 됩니다.
